# سامانه هوشمند نوبت‌دهی سوخت

این پروژه شامل **داشبورد وب اختصاصی** + **ربات تلگرام دوطرفه** + **موتور پایش و ثبت خودکار Playwright** است.

## قابلیت‌ها
- **حالت فقط اطلاع‌رسانی (`notify_only`):** مدام سایت را بررسی می‌کند و به محض باز شدن نوبت خالی، با اسکرین‌شات و لینک مستقیم در تلگرام و پنل وب خبر می‌دهد (و بوق هشدار پخش می‌کند).
- **حالت ثبت خودکار (`auto_book`):** به محض باز شدن نوبت مطابق فیلترهای شما (جایگاه، روز، میزان سوخت)، فرم را پر و ثبت می‌کند.
- **پنل وب اختصاصی (`http://127.0.0.1:8000`):** شروع/توقف، بررسی فوری، تغییر تنظیمات زنده، مشاهده لاگ‌ها، مشاهده نوبت‌های باز و اسکرین‌شات.
- **ربات تلگرام دوطرفه:** کنترل کامل با دکمه‌های منو (`شروع پایش`، `توقف`، `بررسی فوری`، `فقط خبر بده`، `ثبت خودکار`، `وضعیت`، `تنظیمات` و دستور `/set`).

## اجرا
```powershell
.\.venv\Scripts\python.exe app.py
```
سپس در مرورگر باز کنید: `http://127.0.0.1:8000`

### راه‌اندازی ربات تلگرام (اختیاری)
1. در تلگرام به `@BotFather` پیام دهید و با `/newbot` یک توکن بسازید.
2. توکن را در پنل وب (بخش «توکن ربات تلگرام») وارد و ذخیره کنید.
3. به ربات خودتان در تلگرام `/start` بفرستید تا `Chat ID` شما نمایش داده شود؛ آن را در پنل وب وارد و ذخیره کنید.
